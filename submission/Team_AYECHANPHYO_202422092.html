01 — Challenge Overview

미얀마어 음성 인식 및 영어·한국어 음성 번역 연구

1. 연구 배경 및 필요성

음성 번역 기술은 서로 다른 언어를 사용하는 사람들이 자신의 언어로 대화할 수 있도록 지원한다. 최근 다국어 음성 번역 모델이 발전하고 있지만, 언어별 지원 범위와 번역 성능에는 차이가 있다. 특히 저자원 언어의 경우 학습에 사용할 수 있는 음성 및 번역 데이터가 제한적이어서, 음성 인식과 번역 과정에서 오류가 발생할 가능성이 있다.

미얀마어의 경우 일부 다국어 모델에서 음성 입력을 지원하지만, 실제 음성 인식과 영어·한국어 번역의 품질은 별도로 평가할 필요가 있다. 또한 모델에 따라 미얀마어 음성 입력이 공식 지원 언어에 포함되지 않는 경우도 있다.

본 연구에서는 이러한 문제에 주목하여, 미얀마어 음성을 입력받아 영어 또는 한국어 음성으로 변환하는 음성 번역 시스템을 개발한다. 특히 미얀마어 음성 인식 오류가 이후 번역 성능에 미치는 영향을 분석하고, 인식 오류를 고려한 번역 모델을 통해 성능 개선 가능성을 검증한다.

2. 문제 정의

미얀마어 음성 인식에서 발생하는 오류는 영어·한국어 번역과 최종 음성 출력까지 영향을 미칠 수 있다. 본 연구는 다음 네 가지 문제를 중심으로 분석한다.

01

유사 발음 및 동음이의어

미얀마어에는 발음이 비슷하거나 같지만 의미가 다른 단어가 있다. 이로 인해 음성 인식 모델이 단어를 잘못 인식할 수 있다.

예시
🔊 미얀마어 음성 ခပ်ယဲ့ယဲ့ 켓옛옛
(희미하게)
Gemma 4B-ASR
(Zero-shot)
→
ခက်ရဲရဲ 케예예
(빨갛게)
Gemma 4B IT - LLM
(Zero shot)
→
“쾌에에 병”
02

ASR 오류의 번역 전파

음성 인식 과정에서 잘못 인식된 단어는 번역 모델에도 전달된다. 따라서 최종 번역의 의미가 달라질 수 있다.

예시
🔊 미얀마어 음성 ရုပ်ရှင်ကား 욧신까
(영화)
Gemma 4B-ASR
(Zero-shot)
→
ယုတ်ရှင်ကား 욧신까
(의미없음)
Gemma 4B IT - LLM
(Zero shot)
→
“요신가지”
03

번역 음성 생성까지의 오류 전파

음성 인식이나 번역에서 발생한 오류는 음성 생성 단계까지 이어질 수 있다. 이 경우 최종 음성이 원래 문장의 의미를 정확히 전달하지 못할 수 있다.

예시
🔊 Myanmar reference ငါ့အတွက်တော့ ဒါက လုံးဝအဓိပ္ပါယ်မရှိဘူး၊ လုံးဝကို မတရားဘူး။
Korean translation ground truth 그게 저에겐 말이 안 되는 것 같았습니다. 확실히 공평하지 않았어요.
↓
English predicted translation He has no manners at all, he is very rude.
Korean predicted translation 그가 도저히 아예 말이 없어요. 도무지 그럴 수가 없어요.
04

목표 언어별 번역 성능 차이

같은 미얀마어 문장이라도 영어와 한국어의 문장 구조와 표현 방식이 다르다. 따라서 목표 언어에 따라 번역 성능이 달라질 수 있다.

3. 연구 목표

본 연구의 목표는 미얀마어 음성을 입력받아 영어와 한국어로 번역하는 음성 번역 시스템을 개발하고, 음성 인식 오류가 최종 번역 성능에 미치는 영향을 분석하는 것이다. 이를 위해 다음과 같은 세 가지 목표를 설정한다.

목표 1

미얀마어 음성 인식 성능 개선

발음이 유사한 단어나 동음이의어로 인해 발생하는 음성 인식 오류를 분석하고, 이를 줄여 정확한 미얀마어 텍스트를 생성한다.

목표 2

ASR 오류의 번역 영향 분석

ASR 단계에서 발생한 철자 오류나 단어 선택 오류가 영어 및 한국어 번역 결과에 어떤 영향을 미치는지 분석한다.

목표 3

언어별 번역 성능 비교

동일한 미얀마어 음성을 입력했을 때 영어와 한국어 번역에서 발생하는 오류를 비교하고, 언어별 번역 성능의 차이와 개선 가능성을 분석한다.

결과 제출 방법

Challenge에 참여한 사용자는 제공된 Evaluation Dataset과 Evaluation Code를 사용하여 모델의 성능을 평가한 후 결과를 제출할 수 있다.

01 모델 평가

제공된 Evaluation Dataset을 사용하여 모델을 평가한다.

02 점수 계산

제공된 Evaluation Code를 사용하여 ASR CER, BLEU, chrF++ 점수를 계산한다.

03 결과 추가

Speech-Recognition-Challenge-2026 GitHub Repository의 메인 폴더(root)에 있는 leaderboard.csv 파일에 Model, Language, ASR CER, BLEU, chrF++ 결과를 추가한다.

04 Pull Request 제출

수정한 leaderboard.csv 파일을 Speech-Recognition-Challenge-2026 GitHub Repository에 Pull Request로 제출한다.

05 Leaderboard 반영

제출된 결과가 확인되고 Pull Request가 승인되면 해당 결과가 웹사이트 Leaderboard에 반영된다.

04 — Evaluation

모든 모델은 동일한 평가 방식과 Evaluation Code를 사용하여 미얀마어 음성 인식 및 영어·한국어 번역 성능을 평가한다.

ASR CER ↓

Myanmar Speech → Myanmar Text

미얀마어 음성을 텍스트로 변환한 결과를 정답 미얀마어 전사문과 비교하여 문자 단위 오류를 계산한다.

CER = (S + D + I) / N
S = Substitution   ·   D = Deletion   ·   I = Insertion   ·   N = Reference characters
계산 예시
Reference : ABCDE
Prediction: ABXDE

S = 1, D = 0, I = 0, N = 5
CER = (1 + 0 + 0) / 5 = 0.20

↓ Lower is better. CER = 0이면 예측 결과가 정답 전사문과 문자 단위로 일치합니다.

BLEU ↑

English / Korean Translation

Prediction ↔ Reference

모델이 생성한 영어·한국어 번역과 정답 번역을 비교하며, 주로 단어 n-gram의 일치 정도를 기반으로 평가한다.

예시
Reference: I like this book.
Prediction: I like this book.
단어 배열이 많이 일치할수록 BLEU 점수가 높아진다.

↑ Higher is better.

chrF++ ↑

English / Korean Translation

Prediction ↔ Reference

모델이 생성한 영어·한국어 번역과 정답 번역을 비교하며, 문자 n-gram과 단어 n-gram을 기반으로 유사도를 평가한다.

예시
Reference: I like this book.
Prediction: I like the book.
문자와 단어의 유사도가 높을수록 chrF++ 점수가 높아진다.

↑ Higher is better.

정확한 CER, BLEU 및 chrF++ 점수는 제공된 Evaluation Code를 사용하여 동일한 방식으로 계산한다.
