Challenge Description

일반적인 TTS 모델은 자연스러운 음성을 생성할 수 있지만, 목표 감정과 감정 강도를 세밀하게 표현하는 데 한계가 있습니다.

이 Challenge에서는 텍스트와 감정 조건을 함께 사용해 감정이 분명하게 드러나는 음성을 생성하고, 감정 일치도와 음질을 평가합니다.

INPUTText + Emotion텍스트와 목표 감정
→
MODELFine-tuned Spark-TTS감정 제어 음성 합성
→
OUTPUTEmotional SpeechWAV 음성

Baseline & Method

Baseline은 Spark-TTS이며, 다음 과정으로 감정 제어 모델을 구성합니다.

  1. Dataset preprocessing

    Expresso 음성을 학습 형식으로 변환하고 감정 조건을 구성합니다. 전처리 코드

  2. Fine-tuning

    Spark-TTS를 Expresso 학습 데이터로 Fine-tuning합니다. 학습 코드

  3. Inference

    텍스트와 목표 감정을 입력해 감정 음성을 생성합니다. 추론 코드
