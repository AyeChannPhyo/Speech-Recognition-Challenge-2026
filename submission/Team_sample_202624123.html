01 / Description

Challenge Description

자연스러운 음성을 생성하는 것만으로는 실제 대화에 필요한 감정 표현을 충분히 전달하기 어렵습니다. 같은 문장이라도 감정의 종류, 강도와 강조 위치에 따라 청자가 받아들이는 의미가 크게 달라집니다.

이 Challenge의 목표는 텍스트와 감정 정보를 조건으로 사용해 의도한 감정이 명확하게 드러나는 음성을 생성하는 것입니다. 참가 시스템은 감정 분류 정확도를 높이는 동시에 음질 저하를 최소화해야 하며, 동일한 평가 데이터와 객관적 평가 모델을 사용해 Baseline과 성능을 비교합니다.

주요 비교 대상은 감정 조건을 입력받는 Baseline과 감정 제어를 추가 학습한 모델입니다. 감정별 성능과 생성 음성의 품질을 함께 살펴보고, 강도 및 단어 강조 조건의 효과는 대표 음성 예시로 확인합니다.

  • Controllability목표 감정과 강도를 안정적으로 표현
  • Naturalness합성 음성의 명료도와 자연스러움 유지
  • Reproducibility코드, 데이터와 평가 방법을 명확히 공개

02 / Task

Task Definition

입력 텍스트에 목표 감정과 제어 정보를 결합하고, 해당 조건을 충족하는 감정 음성을 생성합니다.

TASK 1

Emotion Category Control

텍스트와 감정 라벨을 입력받아 happy, angry, sadness, surprise, neutral 중 목표 감정이 인식되는 음성을 생성합니다.

TASK 2

Intensity & Emphasis Control

감정 강도와 강조 단어를 추가 조건으로 사용해 문장 전체의 감정 세기와 특정 단어의 운율을 세밀하게 제어합니다. 조건 변화에 따른 생성 결과는 Examples에서 비교합니다.

INPUTText + Emotion Control문장, 감정, 강도, 강조 위치
→
MODELFine-tuned Emotional TTS조건부 음성 토큰 생성 및 복원
→
OUTPUTEmotional Speech목표 조건이 반영된 24 kHz WAV

03 / Method

Baseline & Proposed Method

Baseline system

Baseline은 단일 단계 LLM 기반 음성 합성 모델인 Spark-TTS를 사용합니다. 동일한 텍스트와 화자 조건을 입력해 비교 기준이 되는 음성을 생성합니다.

Baseline repository ↗본인 GitHub Baseline 코드 ↗

Proposed method

제안 방법은 감정 조건 학습과 보상 기반 최적화를 추가해 감정 제어 성능을 강화합니다. 아래 순서로 데이터를 준비하고 모델을 학습한 뒤, 평가 문장에 대한 음성을 생성합니다.

Baseline과 제안 모델은 동일한 텍스트, 화자 조건, 음성 샘플링 설정을 사용합니다. 모델 구조와 학습 방법의 차이만 결과에 반영되도록 구성하며, 전처리부터 평가까지의 코드는 팀 GitHub Repository에서 확인할 수 있도록 연결합니다.

  1. Dataset preparation

    모든 음성을 24 kHz mono로 변환하고 텍스트를 정규화합니다. 감정 라벨, 강도와 강조 위치를 조건 토큰으로 변환하고 학습·검증·평가 데이터를 분리합니다.

    Preprocessing code ↗

  2. Emotion-controllable fine-tuning

    Spark-TTS의 음성 표현을 유지하면서 LLM 부분을 감정 조건부 생성 방식으로 Fine-tuning합니다. 텍스트와 제어 토큰을 입력해 목표 감정의 음성 토큰을 예측합니다.

    Training code ↗Config ↗

  3. Reward-guided refinement & inference

    감정 일치도와 운율 제어 신호를 보상으로 사용해 모델을 추가 최적화합니다. 추론 단계에서는 문장, 목표 감정과 선택적 강조 위치를 입력해 최종 WAV 파일을 생성합니다.

04 / Dataset

Dataset

학습 데이터와 평가 데이터를 분리하고, 각 Dataset의 사용 목적과 전처리 코드를 명시합니다.

DatasetSplitScalePurposeCode

ESD ↗ Evaluation 5 emotions × 100 감정별 생성 음성 평가 Preprocessing

Evaluation에는 학습에 사용하지 않은 문장과 화자를 사용합니다. 최종 평가 세트는 다섯 감정 클래스별 100개, 총 500개 음성으로 구성합니다.

05 / Evaluation

Evaluation Setup

모든 시스템은 동일한 500개 텍스트와 감정 조건으로 음성을 생성하며, 동일한 평가 모델과 설정을 적용합니다.

happy, angry, sadness, surprise, neutral 데이터를 각 100개씩 사용합니다. 생성 음성은 24 kHz WAV로 저장하고 별도 후처리 없이 감정 일치도와 음질을 평가합니다.

MetricEvaluatorCalculation
Emotion Accuracy ↑Primary metricemotion2vec-plus-large생성 음성의 예측 감정과 목표 감정이 일치하는 비율
NISQA ↑Speech qualityNISQA참조 음성 없이 추정한 음질 점수를 전체 생성 음성에 대해 평균
Class-wise Accuracy ↑Per-emotion analysisemotion2vec-plus-large동일한 감정 예측을 사용해 감정 클래스별 정확도를 계산

감정 라벨 매핑과 평가 모델 설정은 모든 시스템에 동일하게 적용합니다. ↑는 높을수록 좋은 지표입니다.
