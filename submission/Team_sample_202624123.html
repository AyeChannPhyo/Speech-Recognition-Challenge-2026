Goal

작성 안내

만들고 싶은 기능과 해결할 문제를 1~2문장으로 작성합니다.

작성 예시

텍스트와 목표 감정을 입력받아 해당 감정이 표현된 음성을 생성하는 TTS 시스템을 구현합니다.

Method

작성 안내

사용한 모델과 주요 처리 단계를 순서대로 적고, 코드나 모델 링크를 함께 연결합니다.

  1. Base TTS 모델 선택

    Spark-TTS를 Base model로 사용합니다.

  2. 감정 음성 Fine-tuning

    Expresso 학습 데이터로 감정과 강조 표현을 학습합니다. 본인 GitHub 코드

  3. 감정 제어 성능 평가

    ESD와 emotion2vec-plus-large를 사용해 목표 감정과 생성 음성의 일치도를 평가합니다. 본인 GitHub 평가 코드
